# Project 3 – SQL Data Analysis

## Overview
This project focuses on analyzing an e-commerce orders dataset using SQL.

## Objectives
- Retrieve and filter data using SELECT and WHERE
- Sort data using ORDER BY
- Perform aggregations using COUNT, SUM, and AVG
- Analyze data using GROUP BY
- Filter grouped results using HAVING
- Calculate percentage contribution of each product to total sales

## Tools Used
- PostgreSQL
- SQL

## Dataset
The dataset contains 1,000 order records with information such as products, quantities, prices, payment methods, order status, and total prices.

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- COUNT
- SUM
- AVG
- GROUP BY
- HAVING
- Subqueries
